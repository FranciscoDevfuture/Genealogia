Esse projeto é sobre a construção de uma Árvore genealógica para fins didáticos
# 🌳 Árvore Genealógica em Python

Aplicação desktop desenvolvida em *Python + CustomTkinter* para criação e visualização de uma *árvore genealógica interativa*, utilizando Canvas para desenhar pessoas e conexões familiares.

O projeto simula uma família fictícia (Família Silva) para demonstrar a estrutura de dados, relacionamentos e renderização gráfica.

---

## 📌 Funcionalidades

- Cadastro de pessoas (nome, nascimento, profissão)
- Relacionamento entre pais e filhos
- Visualização gráfica em formato de árvore
- Interface moderna com CustomTkinter
- Estrutura orientada a objetos
- Base preparada para salvar dados em JSON ou banco de dados

---

## 🛠️ Tecnologias utilizadas

- Python 3
- Tkinter (Canvas)
- CustomTkinter
- Programação Orientada a Objetos (POO)
